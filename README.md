# Modpack issues

Bug reports and suggestions for the Pixel Dream Studios modpacks: Arcadia: Shadowfall, Avalon
Reborn, Create: Industrialized Tech, Fantasy MC, Legacies 26, New Dawn [RPG] and Valor. Arcadia
[RPG] is no longer maintained.

[Report a bug](https://github.com/Pixel-Dream-Studios/modpack-issues/issues/new?template=bug.yml) ·
[Suggest something](https://github.com/Pixel-Dream-Studios/modpack-issues/issues/new?template=suggestion.yml)

Before you report a bug:

- Update to the newest version of the pack.
- Check that it still happens without mods, resource packs or shaders you added yourself.
- Search the open issues. If yours is there, add to it instead of opening another.

A bug report needs the pack, its version, and the game log: `logs/latest.log` in the instance
folder, plus the newest file in `crash-reports/` if the game crashed. Drag the files into the
form.

Questions and help with setup: [Discord](https://discord.pixeldreamstudios.net). Guides:
[wiki](https://wiki.pixeldreamstudios.net).
